How to read the visuals

This page explains the visual metaphor once, so the rest of the repository can stay purely scientific.

The three panels and what they mean

One panel asks whether people with similar movement patterns cluster, and whether wearables separate Parkinson’s from controls.

One panel shows a time dependent gap summary where peaks suggest transitions and a flat region suggests stability.

One panel shows a dense similarity network as a visual cue for global structure and rewiring.

Some viewers do not see a face at first. When told there is a face, many suddenly see it. This is a useful example of how interpretation can change when context is added.

Some people instead report a moon in the sky, a mountain, and phytoplankton in the ocean. These alternative readings are acceptable because the scientific meaning is in the questions above, not in any single artistic interpretation.
